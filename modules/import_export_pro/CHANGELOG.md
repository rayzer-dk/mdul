# Changelog

## 3.6.9

- Certified runtime syntax/API compatibility for PHP 7.4–8.5.
- Removed three PHP 8.5 deprecated curl_close() calls.
- Added explicit CSV escape arguments to eight fputcsv() calls for PHP 8.4+ compatibility while preserving the previous CSV format.
- Fixed diagnostics to report PHP 7.4–8.5 correctly.
- Removed misleading licensing wording from the About section because this module does not contain a License Client.

## 3.6.6

- Полный административный импорт переведён на постоянную InnoDB-очередь с dry run, review и ручным применением выбранных строк.
- Добавлены worker token, lease, heartbeat, безопасное восстановление, повтор ошибок и транзакционное завершение строк.
- Запрещён резервный поиск товара; добавлена блокировка неоднозначных ключей.
- Добавлены серверные профили «Только цены», «Только остатки», «Цены и остатки», «Только новые», «Только существующие».
- Добавлены индивидуальные политики полей.
- Исправлена мультимагазинность: импорт больше не публикует товары и производителей во всех магазинах автоматически.
- Исправлены мультиязычные SEO URL без удаления URL других магазинов и языков.
- Исправлены атрибуты: отсутствие колонки больше не удаляет характеристики.
- Полностью переработаны опции: одна product_option на опцию, несколько значений, компактный формат и структурированный JSON.
- Добавлена полная поддержка noindex, Meta H1, главной категории и связей со статьями ocStore 3.0.4.1.
- Добавлен импорт и экспорт магазинов, фильтров, загрузок, связей, макетов, скидок, акций, наград и периодических платежей.
- Добавлен безопасный реестр поставщиков и подтверждаемая синхронизация отсутствующих товаров.
- Исправлена совместимость нового реестра со штатными таблицами поставщиков Import Export Pro.
- Cron ограничен обновлением цен и/или остатков только существующих товаров.
- Усилена загрузка изображений: SSRF, SSL, MIME, сигнатура, размер, расширение и безопасный путь.
- Усилена очистка HTML.
- CSV-экспорт переведён на пакетную потоковую выдачу и защищён от CSV Formula Injection.
- Добавлен расширенный экспорт стандартных данных и JSON-структур для обратного импорта.
- Исправлена защита сохранённого пароля Basic Auth.
- Добавлена автоматическая идемпотентная миграция схемы при файловом обновлении.
- Версия согласована в install.xml, контроллерах, настройках и интерфейсе.
